# 1. O que é NMAP

**Nmap (Network Mapper)** é uma ferramenta de linha de comando pra descobrir dispositivos numa rede e mapear **quais portas estão abertas** neles — essencialmente, ele testa uma faixa de IPs e portas e reporta o que está "vivo" e o que está "escutando".
 
É a ferramenta que junta tudo que você já estudou: ele varre **IPs** dentro de uma **rede**, testa **portas** uma a uma, e tenta identificar **qual serviço** está rodando em cada uma que encontra aberta.


# 2. IP/Hosts

## 2.1 Descoberta de hosts ativos

Varre um endereço de IP e diz SUBNETS (IPs) estão "vivos" (respondendo), sem escanear nenhuma porta. É o primeiro passo quando você não sabe o que existe numa rede.

```
nmap -sn IP/24
```

Ele decide como testar cada IP dependendo do contexto:
- **Rede local** → usa ARP (mais confiável, já que está na mesma camada 2)
- **Rede remota** → usa ICMP (ping), ou tenta TCP em portas comuns se ICMP estiver bloqueado

## 2.2 Resolução de DNS reverso

Pra cada host encontrado, tenta descobrir o **nome** associado ao IP.

```
nmap -R 192.168.0.0/24
```
```
Nmap scan report for roteador.local (192.168.0.1)
Nmap scan report for notebook-joao (192.168.0.15)
```

Pra desativar (mais rápido, sem tentar resolver nome):
```
nmap -R -n 192.168.0.0/24
```

## 2.3 Métodos alternativos de detecção de host

Úteis quando o ping normal (ICMP) está bloqueado por firewall — o nmap tenta outras formas de provocar uma resposta. 

```
nmap -PE 192.168.0.1              # ping ICMP echo (padrão tradicional)
nmap -PS22,80,443 192.168.0.1     # tenta TCP SYN nessas portas
nmap -PA80 192.168.0.1            # tenta TCP ACK
nmap -PU 192.168.0.1              # tenta UDP
```

Se ICMP estiver bloqueado, mas a porta 80 responder a um SYN, o nmap já conclui que o host está ativo.

## 2.4 Especificação de alvos

Formas diferentes de dizer quais IPs/hosts você quer varrer.

```
nmap 192.168.0.1                    # um IP único
nmap 192.168.0.1-50                 # faixa
nmap 192.168.0.0/24                 # notação CIDR (sub-rede inteira)
nmap 192.168.0.1 192.168.0.5        # múltiplos IPs específicos
nmap -iL lista.txt                  # lê alvos de um arquivo
nmap google.com                     # resolve domínio pra IP automaticamente
```

## 2.5 Traceroute integrado

Mostra o caminho (rota, hops) até cada host, junto do scan.

```
nmap --traceroute IP
```

# 3. Portas

## 3.1 Descobrir o estado de uma porta

Pra cada porta testada, o nmap retorna um estado:

- **open** — algo está escutando ali
- **closed** — o host respondeu, mas nada está escutando
- **filtered** — não deu pra saber, tem firewall bloqueando/dropando o pacote
- **unfiltered** — acessível, mas indeterminado se está aberta ou fechada (raro)

```
nmap IP
```

## 3.2 Técnicas de scan

Formas diferentes de testar o estado de uma porta — cada uma com um trade-off entre velocidade, confiabilidade e discrição.

```
nmap -sT IP       # TCP Connect — handshake completo, mais lento, mais detectável
sudo nmap -sS IP  # SYN scan — "half-open", padrão, mais rápido/discreto
sudo nmap -sU IP  # UDP scan — mais lento, menos confiável
sudo nmap -sA IP  # ACK scan — só mapeia se tem firewall no caminho
sudo nmap -sF IP  # FIN scan — técnica evasiva
```

## 3.3 Selecionar quais portas testar

```
nmap IP             # padrão: ~1000 portas mais comuns
nmap -F IP          # fast: ~100 portas mais comuns
nmap -p 80,443 IP   # portas específicas
nmap -p 1-1000 IP   # faixa
nmap -p- IP         # TODAS as 65535 portas
nmap -p U:53,T:22 IP # mistura UDP e TCP
```

## 3.4 Identificar serviço e versão

Além do estado, tenta descobrir **o que** está rodando na porta aberta.

```
nmap -sV IP
```
```
PORT    STATE SERVICE VERSION
22/tcp  open  ssh     OpenSSH 8.2p1
443/tcp open  https   nginx 1.18.0
```

## 3.5 Scripts focados em porta/serviço (NSE)

Depois de identificar o serviço, roda scripts específicos pra aquele tipo de porta.

```
nmap -p 80 --script http-title,http-headers IP
nmap -p 445 --script smb-enum-shares IP
```
